                                React Questions

1. What is JSX?
JSX lets us write HTML-like code in JavaScript.It makes React UI easier to write.

2. Props vs State?
Props pass data from parent to child.State stores changing data in a component.

3. What is useState?
useState stores and updates data.I used it to store selected technologies.

4. What is useEffect?
useEffect runs code after rendering.It can be used to load JSON data.

5. Why use key in map()?
A unique key helps React identify each list item.

6. What is conditional rendering?
It means showing something based on a condition.I used it to show the empty stack message.

7. How does parent-child data work?
The parent sends data through props.The child can update the parent's state using a function passed through props.
